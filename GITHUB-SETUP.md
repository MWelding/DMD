# GitHub project

Repository: [MWelding/DMD](https://github.com/MWelding/DMD)

[README and direct editing links](README.md) · [Editing guide](EDITING.md)

## Download and run

Clone the repository:

```sh
git clone https://github.com/MWelding/DMD.git
cd DMD
npm run dev
```

Or download the repository as a ZIP, extract it, and run [START.cmd](START.cmd)
on Windows. Install Node.js 20 or newer first. No npm install is needed to run
the site; there are no runtime dependencies.

## Save local changes to GitHub

From the project folder, review changes, then commit and push:

```sh
git status
git add README.md PANEL-TEXT.txt public src scripts test package.json
git commit -m "Update installation content"
git push
```

Add other changed documentation files by name when needed. The image files are
stored directly in Git so README links can open them. Keep image filenames and
extensions unchanged when replacing an existing file, unless you also update its
reference in the code.

## Build and checks

```sh
npm run check:docs
npm test
npm run build
npm start
```

The [GitHub workflow](.github/workflows/checks.yml) runs the documentation-link
check, tests and build on pushes and pull requests. It does not deploy the site.

`dist/` is generated by the build and excluded from Git. Local editor metadata,
environment files, logs and ZIP exports are excluded too. The required source,
web images, font licence, launcher scripts and editable text file are included.

## Hosting

Uploading the project to GitHub stores the source and images. It does not start
the Node server on your PC or VM. Use the [public-server guide](PUBLIC-SERVER.md)
to run it on a VM, or build `dist/` for an ordinary static host. The [editing
guide](EDITING.md#bring-github-edits-into-your-running-copy) explains how to sync
GitHub changes to the running installation.
